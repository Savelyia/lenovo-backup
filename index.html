Personal backup utility

Lenovo Backup

Lenovo Backup copies files from its owner's Google Drive to a privately controlled Debian server. It uses rclone and Google's OAuth authorization flow. It is a personal utility, not a public file-sharing service.

What the utility does

After the owner grants permission, the utility lists and downloads Drive files for local backup. It requests the read-only permission drive.readonly. It does not upload, rename, or delete files in Google Drive.

Unchanged files are skipped. Updated files replace the current local copy. Files removed from Drive remain in the local backup. Supported native Google documents are exported to ordinary file formats; this does not preserve every Google feature or the document's complete revision history.

Private data stays off this website

This website only explains the utility. It does not provide a sign-in form, store OAuth credentials, or display backup files. Authorization is completed on Google's own website; backup data is stored separately on the owner's server.

Your permissions

The owner can revoke the utility's access in Google Account connections. Revocation stops future authorized access but does not automatically remove files already downloaded to the local backup.
